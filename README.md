# BlackVault Finance and Research

Static research-house site for **finance.blackvault.co.ke**, in the BlackVault stage-two design. No frameworks, no dependencies.

- Homepage: research areas, interactive research agenda, latest research with search, prediction ledger, method
- Pages: eight research areas, prediction ledger, method and standards, request research, subscribe, disclaimer
- Content is Markdown in `content/`; run `python3 build.py` (see PUBLISHING.md)
- RSS, sitemap, client-side search and Open Graph metadata included
- Starts honestly: no publications exist yet, and the site shows its agenda, method and an open ledger instead of invented research.

Deploy: see DEPLOY.md.
